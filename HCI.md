# HCI - Polaris

Progressive disclosure L1 simple → L2 technical → L3 raw. Every recommendation answers WHY/WHAT/BENEFIT/RISK/WHAT CHANGES/UNDO/REBOOT.

Components: Dashboard (Health 82/100 with breakdown), Problem cards (severity, impact, evidence), Plan review, Transaction timeline, Auth prompt, Before/After (Δ%, confidence), History/Rollback.

Interaction: [Scan] → [Analyze] → [Create Plan] → [Review] → [Authorize] → [Apply] → progress → [Verify] → [Keep|Rollback] → [Reboot if needed]. Never hide modifies, never fake progress, error recovery actionable ("Authorization denied - no changes applied [Try Again]").

Accessibility: keyboard nav, screen-reader labels, not color-only, contrast, scalable.

Modes: Beginner/Advanced/Expert - safety stays active, Expert ≠ disable safety.
